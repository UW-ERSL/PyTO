# pyTO: Python-based Topology Optimization

## Overview

`pyTO` is a Python-based module designed for easy implementation and execution of Topology Optimization (TO). It provides functionalities for various Finite Element Analysis (FEA) capabilities with different element types and supports Topology Optimization for objectives such as stiffness, stress, and compliance mechanisms, with plans for more.

## Features

* **Finite Element Analysis (FEA):**
    * Supports various element types (e.g., `hex`, `tet`).
    * Modules for structural, thermal, and transient thermal analysis.
* **Topology Optimization (TO):**
    * **Methodologies:** Includes both **SIMP (Solid Isotropic Material with Penalization)** and **Level Set Methods**.
    * **Optimization Objectives:**
        * Optimization for stiffness.
        * Optimization for stress.
        * Optimization for compliance mechanisms.
    * Includes common TO components like filters and material models.
* **Modular Design:** Easy to extend and integrate with other Python projects.

## Installation

To install `pyTO` and its dependencies, follow these steps:

1.  Navigate to the root directory of the `pyTO` project.
2.  Install the required Python packages using `pip` and the `pyTOLibs.txt` file:

    ```bash
    pip install -r pyTOLibs.txt
    ```

    * **Note:** It is recommended to use a virtual environment for your project to manage dependencies effectively.
